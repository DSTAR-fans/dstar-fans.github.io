Software

Doozy, Peanut, D-RATS, RS-BA1, and mobile apps for D-STAR.

Doozy - No repeater nearby? No hotspot? Got an Icom radio and Windows 10 or Windows 11? Just connect your radio to your Windows PC with a USB datacable and connect it to your favorite D-STAR reflector/repeater. Wou can make QSO’s via your Windows PC on DSTAR ( DPLUS, DEXTRA, DCS and XLX ).

Peanut - On the Peanut you can talk with HAM amateurs around the world via an Android device, network radio or Windows PC. Peanut is free and only for HAM radio amateurs.

D-RATS - A multi-platform integrated tool for communication using D-STAR radios. With only a pair of radios (or an entire repeater stack) a variety of data transmission methods are supported, including:

  1. Instant-message chat
  2. Automatic beacon messages
  3. File transfers with error detection
  4. Structured forms
  5. GPS position reports

Icom RS-BA1 IP Remote Control Software — This software allows remote control of some Icom radios including the popular QRP radio, the IC-705. On that page we explain some of the details of using the app to control D-STAR capabilities of supporting radios (YOUR / RPT values—see also call sign mnemonics).
